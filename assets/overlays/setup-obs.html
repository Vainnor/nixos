Vainnor OBS setup

Creates the scenes and browser sources for the overlay pack. It only adds things. Existing scenes and sources are left alone, and nothing is deleted.

Before you start
  1. OBS is open. Go to Tools > WebSocket Server Settings > tick Enable WebSocket server. Note the password (or show the connect info).
  2. You are not streaming or recording right now (OBS won't let this page change the canvas while live).
  3. Unzip the pack to a permanent folder and have its full path ready.
